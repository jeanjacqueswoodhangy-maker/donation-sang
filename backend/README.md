# Backend Don de Sang Solidaire

Backend propre en Node.js, Express et MySQL.

## Installation

1. Installer les dépendances:

```bash
npm install
```

2. Créer la base MySQL avec `database.sql`.

3. Créer le fichier `.env`:

```bash
copy .env.example .env
```

4. Mettre votre mot de passe MySQL dans `.env`.

5. Lancer:

```bash
npm start
```

## Test

Ouvrir:

```text
http://localhost:3000/api/health
```
